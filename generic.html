Embedded Firmware & IoT Development

As a mechatronics engineer, my primary technical focus lies in designing reliable firmware architecture and optimizing embedded system frameworks. Driven by the need for hardware determinism, power efficiency, and stable multitasking pipelines, I transitioned from entry-level abstraction platforms to working natively within professional industrial tooling ecosystems.

Advanced Control Architecture via ESP-IDF

My core microarchitecture development cycles revolve around the ESP32 silicon core. By shifting away from standard Arduino wrappers and adopting the bare-metal ESP-IDF (Espressif IoT Development Framework), I develop firmwares that cleanly leverage FreeRTOS primitives. This shift allows me to build applications with explicit control over task scheduling, task prioritization, dynamic memory allocation, and hardware interrupts.

Hardware Integration & Implementation

Reliable code is only half the battle; it requires well-routed silicon paths to live on. Using Autodesk Fusion 360, I develop synchronized custom electronic schematic libraries and design PCB layouts engineered to protect high-frequency signals. My current workspace acts as an iteration bench where I build, flash, and instrument physical microcontrollers to refine automated logic under real-world runtime environments.
